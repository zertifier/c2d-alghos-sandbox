# Zertipower solar algorithms (Empower-X C2D)

Copies of the algorithms behind three Empower-X marketplace assets, taken from
the gists their assets pointed at (author: jarogar27-cell), so they can be
versioned here and extended with HTML reports.

| File | Marketplace asset | Original gist |
|---|---|---|
| solar_surplus_forecaster.py | Solar Surplus Forecaster – trained on MareNostrum 5 (image janaroman/solar-surplus-forecaster:1.0) | gist 1a71cb1a76544fdfc112411eef2e1f15 @4e2b29e |
| solar_roi_calculator.js | Solar Production, Savings and ROI Calculator | gist 76ff01b09dc9fe6816df952b7162f155 @e12ee24 |
| solar_irradiation_curve.js | Solar Irradiation Curve | gist eddd500e6d074f2575fcf4090d7b1761 @170b7a3 |

Note: the two .js files say "generated by build.js"; that build project is not
in this repo. Changes made here must be carried over to it, or this copy becomes
the source of truth.

## HTML reports

Each algorithm also writes a self-contained HTML report into /data/outputs
(inline CSS + SVG, no scripts, no network), next to its existing outputs, which
are unchanged:

- solar_roi_calculator.js -> solar_report.html
- solar_irradiation_curve.js -> solar_irradiation_report.html
- solar_surplus_forecaster.py -> surplus_forecast_report.html

The JS files embed empower-x/report/html-report.js between the html-report
markers (refresh with `node tools/inline-report.mjs zertipower-solar/<file>.js`).
The Python file has its own stdlib port with the same look.

## Solar Surplus Forecaster: entrypoint fix needed

ocean-node replaces `$ALGO` with the RELATIVE path `data/transformations/algorithm`
and keeps the image WORKDIR (`/app`), so `python $ALGO` looks for
`/app/data/transformations/algorithm` and fails. Set the asset's container
entrypoint to `python /data/transformations/algorithm`.
